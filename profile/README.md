# Swift ECMA

Use this organization when you need a Swift implementation of an Ecma International standard. There is one package per specification, named `swift-ecma-<number>`, which follows its source document as literally as possible under its own namespace, such as `ECMA_48`. The [repositories](https://github.com/orgs/swift-ecma/repositories) list them by number. If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift ECMA is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by Ecma International.
